# Wise Path Demo

面向 Wise 网站开发兼职岗位制作的跨站学习导航概念原型。

## 在线 Demo

https://bigdu332.github.io/wise-path-demo/

## 核心假设

Wise 的单站内容和功能已经较完整；增加一层按用户目标、经验与时间生成路径的统一入口，可以降低首次访问者理解站点结构的成本，并提升跨站内容流转。

路由不是只替换文案：

- 目标内增加具体任务：美股的宏观/产业/财报、新股的港股/美股/A 股、出海的银行/券商/见证/通信等。
- 经验决定必要的知识前提和行动顺序，不等同于已经开户、购卡或具备资格。
- 每个时间预算独立编排：10 分钟一个入口；30 分钟聚焦必要问题；系统学习增加方法与验证。需要的页面不足时不凑数。
- 覆盖 8 个目标组、28 个任务选项、3 个经验层级与 3 种时间预算，共 252 个配置组合。通信也可从出海服务进入。
- 一句话输入可识别具体任务；明确任务优先于所选目标。无法识别时保留当前选择并如实提示，点击任务可手动修正。
- 每一步给出核对事项，标明登录或预览状态；阅读时间是编辑估计，不承诺完成课程或办理业务。

## 原站核查

2026-10-02 重新检查各站页面用途、课程目录、数据日期口径与访问状态，记录在 [route-review.json](./route-review.json)。这些观察用于安排导航，不代表核验了全部财务数据、课程内容或开户条款。

例如：CHAIN 的具体课程替代宽泛开户入口；ETF 接蓝皮书章节与公开数据工具；IPO 不混排不同市场；通用加密路线不自动进入合约；见证开户仅在明确选择该任务时进入。CHAIN 在当前浏览器会话可读，但后续发现已有会员会话，因此标为可能需要 Wise ID；Crypto 受登录限制的正文未读取。

## 本地预览

```bash
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。

GitHub Pages 仓库把静态文件放在根目录，在该仓库预览时省略 `--directory dist`。测试脚本兼容两种目录结构。
